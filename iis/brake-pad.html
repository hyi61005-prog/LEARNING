Quy luật phân bố đều

Tính bề rộng má phanh

Giả thiết áp suất phân bố đều trên bề mặt ma sát (p = const). Phù hợp má mới / tiếp xúc tốt; khi mòn nhiều thường chuyển sang quy luật mòn đều.

Chọn kiểu má

Diện tích vành: A = π(R₂² − R₁²) = Fₐ / p → suy ra bề rộng b = R₂ − R₁.

p = Fₐ / [π(R₂² − R₁²)] Mₜ = (2/3)·μ·Fₐ·(R₂³ − R₁³)/(R₂² − R₁²) b = R₂ − R₁

Áp suất đều trên cung má: A = b · r · θ → b = N / (p · r · θ).

A = b · r · θ p = N / A ⇒ b = N / (p · r · θ) (θ tính bằng radian; θ° = θ · 180/π)

Xấp xỉ má phẳng chữ nhật: A = b · L = Fₙ / p.

A = b · L = Fₙ / [p] b = Fₙ / ([p] · L)

Giả thiết quy luật phân bố đều

  • Áp suất pháp tuyến p không đổi trên toàn diện tích tiếp xúc.
  • Thường dùng khi má mới, cứng, biến dạng nhỏ, tiếp xúc tốt.
  • Mô men ma sát đĩa lớn hơn quy luật mòn đều (cùng Fₐ, R₁, R₂).
  • [p] lấy theo vật liệu má + đĩa/trống (thường 0.5–2.5 MPa cho má hữu cơ/bán kim).

Đơn vị & lưu ý

  • 1 MPa = 1 N/mm².
  • Kết quả b nên làm tròn lên theo kích thước tiêu chuẩn / khuôn ép.
  • Cần kiểm tra thêm: nhiệt, mòn, hệ số an toàn phanh, cân bằng guốc leading/trailing.
