# 時態｜Ticket 最常用三組

## 規則（只記這三條）

1. **since / for + 時段還在** → 現在完成：`has been` / `have reported`
2. **yesterday / last week / on 1 Oct** → 過去式：`deployed` / `sent`
3. **now / currently / still** → 現在簡單或進行：`remains` / `is working`

## 對照

| 中文感覺 | 英文 |
|----------|------|
| 從早上到現在一直掛 | The site **has been** down since this morning. |
| 昨天已部到測站 | We **deployed** the fix yesterday. |
| 單還在 Pavani | The ticket **remains** with Pavani. |
| 使用者回報過（完成／經驗） | Users **have reported** that… |
| 正在等確認 | We **are waiting** for confirmation. |

## 易錯

- ~~are deploying yesterday~~ → deployed yesterday
- ~~is down since~~ → has been down since
- ~~have deployed yesterday~~ → deployed yesterday（有明確過去時間點就別硬用完成式）

## 自測提示

看到 `since` 先想完成式；看到 `yesterday` 先想過去式。
