# 自然回信｜主管向（少直譯）

## 原則

1. 第一句＝結論（Got it. / Update: still WIP…）
2. 完整主詞＋動詞；第三人稱用 doesn't / does not
3. 暫行做法用 Until this is fixed … for now
4. 一段一件事；結尾 Thank you
